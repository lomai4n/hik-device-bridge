## 检查范围

CTest 包含两个测试入口：

- `bridge_tests`：版本不匹配、初始化/登录/布防失败回滚，撤防/注销/清理失败继续释放，重复退出，退出期间与关闭后的回调；未知码、空指针、零长度、长度越界，有界队列溢出、异常状态在溢出时仍保留，接收器失败计数，多生产线程与关闭并发及计数守恒；密码权限、符号链接、硬链接、FIFO、空密码、换行、NUL、超长输入；动态库缺失、符号缺失、符号齐全仍拒绝真实运行；元数据不包含合成敏感内容。
- `cli_tests`：演示 JSON 字段允许列表、明确模拟标识、最终计数、参数拒绝且不回显敏感值、密码文件检查、真实路径失败、SIGTERM 退出、输出管道断开与满管道失败。

仅有模拟生命周期和通用版本判断；这些检查不等价于厂商 SDK 登录、布防、ABI 或版本兼容性验收。
