# 厂商 SDK 使用与再分发核对

核对日期：2026-10-10。项目原创源码与文档采用 Apache-2.0；厂商 SDK、头文件、样例和配套资料属于另外的许可范围。项目许可不替代厂商授权。本记录是公开条款的核对结果，不是某个实际 SDK 包已获授权的证明。

## 实际查阅的公开依据

1. [官方 SDK 下载页](https://www.hikvision.com/en/support/download/sdk/)的下载确认区指向 [Hikvision Materials License Agreement](https://www.hikvision.com/en/policies/materials-license-agreement/)，并提示下载和使用材料须遵守该协议。本轮读取了下载页，但该目标协议页面的正文获取失败；没有点击同意、下载 SDK 或替用户签约。
2. [官方 HiLook 站公开 MLA](https://www.hilooksecurity.com/europe/policies/materials-license-agreement/)标注最后更新为 2020-01-21，本轮在浏览器中查阅了正文。定义涵盖 SDK、头文件、API、库、模拟器、源码/目标码和技术资料；第 2 节授予受限制、不可转让的使用许可，未明示权利保留。第 3.1(b/c/d/e/f) 节包含复制、分发、修改、集成、反向工程和向他人提供材料的限制，以及明确许可或适用法律的例外；第 5.2 节要求遵守所含第三方软件的条款。该页适用的是 HiLook 下载来源，不能自动当作任意地区和 SDK 版本的合同。
3. [官方 TPP FAQ](https://tpp.hikvision.com/Support/FAQs)区分普通和受限材料；ISAPI、OTAP、HEOP 等受限材料需要双方签署相应协议才能取得。这里只说明其签约流程，不推断所有 Device Network SDK 都需要相同流程。

## 本轮结论与发布边界

- **使用/集成：尚未核验到具体 SDK 包。** 没有实际包的下载来源、版本、随包条款、适用地区和签约记录，不能承诺用户可以在任意产品中使用或集成。公开 MLA 存在集成限制，动态加载本身不能证明已满足许可。使用者必须确认自己的实际授权范围。
- **再分发：本轮没有可据以批准再分发的授权证据。** 公开 MLA 也不能支持“SDK 可自由再分发”的结论。Git、源码包、Release 资产和构建环境均不捆绑厂商材料；不得将二进制、头文件或完整资料另传给下载者，也不得用 Apache-2.0 为其重新授权。
- **第三方依赖：需随具体 SDK 包单独核验。** 它们可能有独立的通知、许可及分发要求；不根据某个搜索结果或其他版本推断所有 SDK 包的依赖。

本次公开内容只包括从零实现的通用层、合成测试、使用文档、许可文本和符号名称探测；没有厂商材料正文、代码或 ABI 布局，真实接入禁用。后续真实接入前，应在忽略的本地目录记录实际包版本/摘要、获取来源、配套许可及授权范围，再核对 ABI 和允许的使用方式。若计划再分发，另行取得覆盖相关组件、受众和分发方式的明确授权；没有证据时继续排除厂商材料。
